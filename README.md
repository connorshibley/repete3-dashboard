# tradingfloor dashboard (auto-published)

Live view of **[PAPER] trading** by an LLM research firm — five agent stages
propose, a deterministic desk of rails decides what is allowed, and every
decision plus the reasoning behind it is recorded in an append-only journal.

Regenerated and pushed automatically by the bot's scheduled job (weekdays,
45 minutes after the open). Nothing here is financial advice; the account is
a paper account and no real money is at risk. Blank panels on the page mean
*unmeasured*, not zero.

Bot code is private; this repo is the page only.
